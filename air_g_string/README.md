## BarLoop で変えたこと

BarLoop が LilyPond ファイルを MusicXML に変換し、弦楽の楽譜をピアノ 2 段にまとめて、両手で弾けるように音を左右の手に振り分けました（一部の音は 1 オクターブ動かし、伸ばす音を短くしています）。BarLoop が変えたこの楽譜も、元と同じライセンスで公開します。

元は弦楽合奏（ヴァイオリン 2 つ・ヴィオラ・通奏低音）の曲です。元の音を全部使い、片手で届かない音は反対の手に移すか 1 オクターブ動かし、伸ばしている音を早めに離して、両手で弾ける形にしています（ニ長調の原曲。ヴァイオリンの G 線だけで弾く編曲ではありません）。

## Changes by BarLoop

BarLoop converted the LilyPond files to MusicXML, combined the string parts into a two-staff piano score, and distributed the notes between the hands so that it can be played with two hands (some notes are moved by an octave, and some held notes are shortened). This modified score is also released under the same license as the original.
