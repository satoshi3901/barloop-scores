# barloop-scores

[日本語](#日本語) | [English](#english)

## 日本語

ピアノ練習アプリ **BarLoop** で使っている楽譜のうち、元の楽譜データのライセンスが CC BY-SA または CC BY のものについて、**BarLoop が変えた楽譜（MusicXML）** を公開する場所です。

- 曲の数：73 曲（CC BY 4.0: 1 / CC BY-SA 2.5: 22 / CC BY-SA 3.0: 12 / CC BY-SA 4.0: 38）
- 元の楽譜データは、[Mutopia Project](https://www.mutopiaproject.org/) と、Knute Snortum さんの [GitHub](https://github.com/ksnortum) などで公開されている LilyPond ファイルです。作成者の皆さんに感謝します。
- BarLoop は、LilyPond ファイルを MusicXML に変換し、再生のためのテンポやペダルの指定を加えています。カノンと G 線上のアリアは、弦楽の楽譜をピアノ 2 段にまとめ、両手で弾けるように編曲しています。曲ごとの変更は、各フォルダの README.md に書いています。

### フォルダの中身

各フォルダ（曲の id）に、次の 2 つがあります。

- `<id>.musicxml`：BarLoop が変えた楽譜（アプリに入っているものと同じ）
- `README.md`：楽譜データの作成者・入手先・元の出版譜・ライセンス（URL）・BarLoop で変えたこと

### ライセンスの条件

- 楽譜ごとにライセンスが違います。**各フォルダの README.md に書いたライセンスが、その楽譜に適用されます。** このリポジトリ全体に 1 つのライセンスがあるわけではありません。
- **CC BY-SA（2.5・3.0・4.0）の楽譜**：使うとき・配るときは、楽譜データの作成者と BarLoop の名前、入手先、ライセンス（URL）を表示してください。変えた場合はそのことを書き、変えたものも **同じライセンス**（同じか、後のバージョンの CC BY-SA）で公開してください。BarLoop が変えたこれらの楽譜も、元と同じライセンスで公開しています。
- **CC BY 4.0 の楽譜（カノン）**：使うとき・配るときは、楽譜データの作成者と BarLoop の名前、入手先、ライセンス（URL）を表示し、変えた場合はそのことを書いてください。
- どの楽譜も「そのまま」の提供で、正しさなどの保証はありません（各ライセンスの免責のとおり）。
- このリポジトリは楽譜だけです。BarLoop アプリのプログラムは含みません。

## English

This repository publishes the **scores modified by BarLoop (MusicXML)** that are used in the piano practice app **BarLoop**, for pieces whose original score data is licensed under CC BY-SA or CC BY.

- Number of pieces: 73 (CC BY 4.0: 1 / CC BY-SA 2.5: 22 / CC BY-SA 3.0: 12 / CC BY-SA 4.0: 38)
- The original score data are LilyPond files published by the [Mutopia Project](https://www.mutopiaproject.org/), Knute Snortum on [GitHub](https://github.com/ksnortum), and others. Many thanks to all the typesetters.
- BarLoop converted the LilyPond files to MusicXML and added tempo and pedal markings for playback. For the Canon and the Air (BWV 1068), the string parts were combined into a two-staff piano score and arranged so that they can be played with two hands. The changes for each piece are described in the README.md in its folder.

### Contents of each folder

Each folder (named after the piece id) contains:

- `<id>.musicxml`: the score as modified by BarLoop (the same file used in the app)
- `README.md`: typesetter, source, original edition, license (with URL), and the changes made by BarLoop

### License terms

- Each score has its own license. **The license stated in the README.md of each folder applies to that score.** There is no single license for the whole repository.
