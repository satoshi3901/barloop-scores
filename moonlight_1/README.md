## BarLoop で変えたこと

BarLoop が LilyPond ファイルを MusicXML に変換し、再生のためのテンポとペダルの指定を加えました。BarLoop が変えたこの楽譜も、元と同じライセンスで公開します。

この曲は、ベートーヴェンが『曲全体をペダルを使って弾くこと（senza sordino）』と指示しています。元の楽譜にはペダル記号がないため、和音の変わり目に合わせて、このアプリでペダル記号を書き加えています。
