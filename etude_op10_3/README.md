## BarLoop で変えたこと

BarLoop が LilyPond ファイルを MusicXML に変換し、再生のためのテンポとペダルの指定を加えました。再生のために、楽譜の書き方を一部直しています。BarLoop が変えたこの楽譜も、元と同じライセンスで公開します。

テンポは、楽譜データの編者が再生用に書いた速さの流れ（Lento ♪=72、poco più animato ♪=100 など）を使っています。元の楽譜データにはペダル記号が一部（42〜45 小節）にしかないため、それを外し、和音の変わり目に合わせて、このアプリで曲全体にペダル記号を書き加えています。

## Changes by BarLoop

BarLoop converted the LilyPond file to MusicXML and added tempo and pedal markings for playback. Some notation was also edited for playback. This modified score is also released under the same license as the original.
